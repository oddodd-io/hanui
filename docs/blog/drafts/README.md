# 글 초안 보관

발행 큐(`apps/docs/blog-queue/`)에서 **뺀** 글을 둔다. 여기 있는 글은 발행되지 않는다.

큐는 날짜가 되면 자동으로 나가므로, "지금은 내보내면 안 되는" 글을 큐에 두면 안 된다.
날짜만 지우는 방법도 있지만 그러면 재고 집계에서 빠진 채 큐에 영원히 남아
`findUndated`가 매번 경고한다 — 그건 "프론트매터 결함"이지 "보류"가 아니다.
